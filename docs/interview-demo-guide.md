# 豆豆的成长日记：面试演示讲解稿

## 一句话介绍

“豆豆的成长日记”是一款把主动学习嵌入宠物养成的 AI 学习产品。孩子不是被要求完成一套题，而是为了照顾自己的宠物，在喂饭和玩耍时把知识讲给它听。

## 现场演示路径

1. 先展示首页：豆豆饿了，想吃小鱼饼。
2. 点击“教豆豆，获得小鱼饼”。
3. 用“空心结构”解释第一层原因，再用“水的托举”补充第二层原因。
4. 展示奖励卡：孩子获得小鱼饼。
5. 点击“喂给豆豆”，豆豆在吃饭时提出错误观点：“只要东西很轻，就一定能浮起来。”
6. 选择“不一定”，说明孩子需要理解并纠正宠物，而不是机械答题。
7. 进入虚拟实验，调整船体宽度和货物重量，运行实验。
8. 结束时展示“豆豆学会了”和理解度反馈。

## 面试时强调的产品价值

- 游戏负责让孩子愿意回来，教会宠物负责让孩子真正组织知识。
- 宠物不是只会说“你真棒”，而是会提出可控的错误和新情境问题。
- 食物是即时的情境奖励，但长期目标是让孩子看到宠物因自己而成长。
- 评价重点是独立解释和新情境迁移，不是答题速度、字数或在线时长。

## 诚实说明的 Demo 边界

- 当前语音按钮使用模拟识别，正式产品可接入语音识别服务。
- 当前知识内容和反馈规则是针对“浮力”主题预设的，正式产品需要课程知识结构和审核流程。
- 当前实验是浏览器内的安全模拟，不会指导孩子直接完成危险的现实实验。
