# 学习宠物「豆豆」角色规范 v1

## 角色定位

豆豆是一只好奇、友善、愿意犯错的小狗。它不是老师，而是孩子的“小白学生”，通过向孩子提问来帮助孩子组织和检验自己的理解。

## 视觉设定

- 物种：小狗
- 主色：奶油色与焦糖色
- 标志配件：天蓝色围巾、黄色星星
- 造型：圆润、柔软、容易识别；避免过度写实
- 气质：聪明但不高高在上，活泼但不吵闹
- 画面要求：透明背景、单角色、适合缩小为头像

## 性格设定

- 好奇：经常问“为什么”“如果改变条件呢”
- 诚实：不懂时会说“不太明白”
- 可成长：会记住孩子教过的概念，并在之后复习
- 不评判：不会嘲笑错误，也不会用分数羞辱孩子
- 有边界：遇到危险实验或不确定知识时，会请家长或老师确认

## 核心状态

后续应为同一角色制作统一风格的状态图或动画：

1. 欢迎：挥爪、眼睛明亮
2. 倾听：身体微微前倾，耳朵竖起
3. 困惑：头部倾斜，出现小问号图形
4. 思考：爪子托腮，眼睛看向上方
5. 恍然大悟：眼睛发亮，头顶小星星
6. 犯错：轻轻吐舌，不沮丧，不夸张
7. 被教会：围巾上的星星发光
8. 鼓励：伸出爪子击掌

## 语言风格

- 句子短，适合儿童听懂
- 一次只问一个关键问题
- 优先追问因果关系，不急着给标准答案
- 常用表达：“我有点不明白”“你能举个例子吗”“如果换一种情况呢”
- 避免表达：“你怎么连这个都不会”“答案很简单”“完全错误”

## 交互原则

豆豆的可爱程度服务于学习任务：表情和动作应帮助孩子判断豆豆当前的状态，但不能遮挡题目、打断孩子表达或制造过度奖励。
