# 帕恰形象设计方向

根据用户提供的视频画面提取外观参考，不根据字幕推断犬种。用户确认概念图后，已接入网页角色，使用两张透明姿态图集驱动互动。

## 识别特征

- 奶白色蓬松毛发，圆润下垂的毛耳朵。
- 黑色圆眼、短嘴鼻、小黑鼻头，眼周有轻微暖色。
- 身体小巧，胸腹连贯，腿短但有清晰的肩、髋和落脚位置。
- 保留真实小狗的重心与姿态，不采用人形躯干或独立管状腿。

## 动画造型要求

先统一坐姿、站姿、侧面小跑、闭眼撒娇、蜷卧睡觉五种姿势。跑动需显示前后腿交替及耳朵惯性；撒娇来自头颈倾斜和重心靠近；睡觉需要真实折腿卧下，不能只把整个身体压扁。毛发用于遮住关节衔接，但不能掩盖错误肢体结构。

## 本次概念图

使用内置图像生成，以视频关键帧拼图为身份参考。柔和 2.5D 手绘游戏风，奶白毛色，原生小狗比例，左侧大幅坐姿和右侧四种姿势，无服装道具。视频原文件不加入网站发布产物。

## 网页素材与使用约定

- `assets/pets/pacha-concept-v1.png`：用户确认的概念图，仅作设计参考。
- `assets/pets/pacha-poses.png`：内置图像生成制作的 4×2 透明姿态图集；按行排序为坐姿、眨眼、左倾撒娇、右倾撒娇、站立、嗅闻、蜷卧睡觉、开心。
- `assets/pets/pacha-trot.png`：内置图像生成制作的 4×2 连续右向小跑图集，左向播放使用水平镜像。
- 图像尺寸均为 1774×887，网页以百分比背景定位播放，不裁切或重绘生成毛发。呼吸缩放仅作为姿态绘图的补充。
- 采用有限帧的 2D 动画，不是 3D 骨骼模型。动作组切换可能仍有姿势跳变；未来可添加专门的起身、蹲下和转身过渡帧。

生成提示要点：以已确认帕恰概念图锁定身份；奶白蓬松毛发、黑圆眼、短嘴鼻、下垂毛耳、自然紧凑犬类身体；严格四列两行等大单元，透明背景、同尺度、完整身体、无服装和道具。小跑组要求八个顺序步态帧、交替对角落脚、耳朵随动和统一右向。姿态组要求不同表情和真实折腿卧下。

验证：运行 `node scripts/check_companion.cjs` 覆盖小跑帧推进、移动、撒娇姿态、追球返回、睡觉唤醒、暂停、连续打断和学习互动。运行 `node scripts/build_static.cjs` 同步发布图集。
