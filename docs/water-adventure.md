# 水上探险：从玩耍到教帕恰

流程：钢珠入水 → 空心钢船入水 → 帕恰提问 → 孩子自由解释；不会时可选分镜动画、铝箔实验或文字 → 返回解释 → 三个概念追问 → 一次性小鱼饼奖励 → 原有喂食、承载模型与成长地图。

分镜可自动播放、暂停、逐幕前进和重播。减少动态效果偏好下默认逐幕。切到后台暂停。分镜为科学剖面示意与已有帕恰素材，并非实拍视频。

自由文本仅显示在本页，不发送给模型、不自动评分。后续结构化追问检验下沉时仍有浮力、空心船排水与承载限度。只有完成自由解释并正确完成三个追问才发放一次奖励；看完材料不会自动过关。无持久存储，刷新重置。语音按钮不再模拟填入正确答案。

科学要点：浮力等于排开液体的重量；钢珠下沉仍受浮力；空心船可在进水前排开足够多的水；静浮时浮力与总重量平衡；空心不保证不沉。保留的承载模型改用明确的理想矩形船体体积与质量关系，而非无单位阈值。该模型不处理稳定性、变形及真实船舶安全。

内容核对：
- https://openstax.org/books/college-physics/pages/11-7-archimedes-principle
- https://www.sciencebuddies.org/stem-activities/aluminum-foil-boats-float

实验只需铝箔和浅水盆，成人陪同，不要求钢珠或真实宠物参与。允许记录“两个都浮”和其他真实结果，提示检查残留空气、水面张力和漏水，不强行改写观察。
